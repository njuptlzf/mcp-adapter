    - `addDirectTools(pi, ctx)` → `addDirectTools(agentapi: AgentAPI, ctx: AgentContext)` replace `pi.getFlag` with `agentapi.getFlag`

    **Step E — Verify no ExtensionAPI/ExtensionContext imports remain:**
    After migration, `grep "Extension" commands.ts` must return 0 matches.

    **Step F — Update from-callers in mcp-panel.ts / mcp-setup-panel.ts:**
    These files call commands.ts functions with `(pi, ctx)` or `(state, ctx)`. After migration:

    - So panel files should be updated to accept AgentContext (type change only), but they don't need to call adaptPiContext themselves unless they bypass index.ts
