<objective>
Decouple the elicitation handler from Pi-specific UI context and the tool-result renderer from Pi TUI `Text` by adopting generic `UISystem` and a string-based renderer output. Pi-specific Text wrapping moves to a dedicated boundary adapter.

Purpose: Allow non-Pi agents to reuse elicitation and rendering logic while Pi keeps its existing TUI rendering behavior.
Output: New `adapters/pi-renderer.ts`; refactored `elicitation-handler.ts` and `tool-result-renderer.ts` with no Pi UI/TUI imports.
</objective>
