## Decomposition Strategy (Risk-Aware)

The 6 `agentapi.on/regist*` calls all share the closure variables `state`, `initPromise`, `lifecycleGeneration`. **Mechanical extraction of each as a module-level function is risky** — would require either:
- **Option A**: Refactor closure into a `Lifecycle` class with `state`/`initPromise`/`generation` as instance fields (most invasive)
- **Option B**: Extract pure helpers only (`shutdownState` can become module-level since it only reads `currentState`)
- **Option C**: Add intra-function section dividers + type-aliased comments to make merge conflicts at line-level (least invasive)

**Recommended: Option B (extract `shutdownState` only) + Option C (section dividers in remaining)**
